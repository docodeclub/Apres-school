# Image & Privacy Guidance

The current site uses real Après School activity imagery. Before production launch:

- Confirm permission to use every child-facing image on the public website.
- Confirm parent/carer consent status for identifiable children.
- Prefer images showing activity, space, staff presence and atmosphere without exposing sensitive details.
- Avoid images that show registers, medical information, surnames, school badges where not approved, or private paperwork.
- Store original images in a controlled location and serve only resized web assets publicly.
- Keep a removal process for any image if consent changes.
